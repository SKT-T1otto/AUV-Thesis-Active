# 新地图等价计算缓存（2026-10-22）

本次实现用户选定的两项：复用重复求交结果；缓存扫描预处理和已经计算完成的兼容结果。地图算法仍为 `coupled_search_v2`，计算实现标记为 `exact_geometry_cache_v1`。没有接入先前审查中的按轴求交候选内核，没有减少射线、地图、粒子、历史或预测规模。

## 实际修改

### 单次构造内的求交复用

`chapter3_bser/experiments/coupled_search_v1/geometry_hypotheses.py`：

- 种子盒与合并盒通过原检查后，复用刚算出的 entry 更新 `best`。
- 接受的盒对应 entry 放入该 `RayConstraints` 自己的缓存；替换旧盒时删除旧条目。
- 最终 `matches` 仍检查所有传感器起点自由，并按原盒顺序折叠求交结果。没有用构造过程中累计的 `best` 替代最终验证。
- 补全地图复用基础支持盒及接受的未知盒结果；被拒绝的随机候选不会批量进入缓存。
- 射线快照使用原拼接、`np.unique` 去重及排序。快照数组只读，新历史创建新快照，不跨重建复用 entry。

原 `RayConstraints.entry` 函数和兼容判定数学内核保持原算法；来源检查另行核对 AST。除法、精度、平行/切线/边界条件、支持厚度缩减、邻居选择和随机尝试顺序保持原样。

### 回合内的公开观测缓存

新增 `geometry_cache.py`，由 `CoupledBelief` 在本回合内持有，几何构造器共用该对象：

- 预处理缓存保存展开起点、方向、世界边界限制、平行掩码、观测距离/命中标志及历史约束行。
- 键包含输入数组的形状、dtype 和精确字节，以及 agent_ids、世界边界、传感器范围；不依赖会重复使用的步号、地图编号或对象地址。
- 兼容缓存额外包含所有有序盒参数和容差，只保存原兼容计算完成后的 `True` 或 `False`，不保存异常。
- 重放中的新地图—扫描组合仍实际计算；没有根据全历史 `matches` 成功就预先假定历史似然全为 1。
- `CoupledBelief._update` 保留原预算检查位置；完整重放、先验、目标传播、负发现证据和归一化操作未修改。
- reset 创建新会话/信念，因此缓存不跨回合共享；不写入模型权重或检查点。

LRU 的保守核算上限为：单射线快照 entry 16 MiB/4096 条；回合预处理 16 MiB/最多 `history_steps+1` 条；兼容结果 4 MiB/4096 条。键及缓存值计入核算；Python 容器自身的额外管理开销受条目数约束。这些是缓存核算上限，不是整个 Python 进程的 RSS 上限。超限只淘汰计算结果，之后重算，不删除观测或改变推断规模。

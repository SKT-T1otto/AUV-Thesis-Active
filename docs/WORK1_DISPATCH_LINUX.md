# 四个新家族的 16 步派艇验证

本试验观测自然 D2 菜单在第 0 步的分配。主问题分别是同一区域是否有两艘搜索艇能在 16 步内实际扫到，以及更换分工后两个冻结预测器能否判断全队沿途覆盖信念质量的增减。每个家族最多两个回合，四个家族合计最多八个回合，每回合最多 32 个物理步。模型训练更新为零。

## 在 Linux 上运行

在项目根目录、已能运行原生 R123 的 Python 环境中执行。

```bash
bash scripts/work1_dispatch_linux.sh
```

可以用环境变量 PYTHON 指定解释器，或给脚本传一个新输出目录。默认结果写在 work 下的唯一目录里。运行结束后终端的 REPORT 指向中文报告，RETURN 指向包含预登记、逐家族预测、物理轨迹及结果的 tar.gz 压缩包。目录已存在时脚本保留原始结果并退出。中断留下的目录保留作诊断。项目依赖见 requirements.txt。也可以直接运行 Python 入口：

```bash
python -B -m tools.work1_linux_dispatch work/my_dispatch_run --execute
```

## 预登记

- 场景取自现有 M20_MOVING_UNKNOWN_MULTI 原生生成器，以种子 202611267、smoke_validation 划分一次性生成四个家族，按生成顺序全部纳入。清单已固化在 configs/work1_dispatch_linux_v1.json。登记时逐项与之前的 42 个不同物理指纹比较，要求障碍布局摘要、目标轨迹摘要、四艇初始两两距离签名均无重合。场景名称可以跨批次重复，配对按实际种子及物理布局核对。首次物理步前记录输入文件摘要和运行环境。预测器只读取当时公开的规划状态、原生候选和公开路径。
- 固定三个搜索艇、一个执行艇、目标信念、原生接令和探测判据、R123 的双跟踪／任务同步／末段设置。初始决策没有历史误差样本，历史联合误差预测器沿用自身的冷启动行为，分箱模型读取原冻结参数。本实验结论适用于出航时刻。后续新的自然调度仍由原生控制器执行。
- 同一原生艇—格心组合只查询一条公开参考路径。复算原空间选择，并用同一组公开参考路径重新计算空间核。只有同样选出原分工、组间拥有完整三艇、无歧义时才做严格对照。缺参考、几何否决、原生选项不足、没有其他可行分工或窗口未观察完整时，保留具体原因。
- 固定空间组选中的任务多重集、可行性和执行艇待命。分别记录一个区域有几艘艇在菜单中、哪些艇确实可交换任务、哪些艇通过 16 步物理下界、哪些可交换艇同时满足公共路径核验。物理下界使用 ceil(max(0,距离−原生探测半径含容差)/(dt×hypot(v_xy_max,v_z_max)))，最小为 1。它允许瞬时加速和直线航行。两艘艇都通过只表示可能；两侧真实接令且分别在同一区域格心有效扫到，才计作已观测竞争。每区的共同候选、原地即覆盖标记、实际交换的两艇、首次扫测步号保留在证据中。
- 历史联合误差和运动状态分箱模型各自计算区域分数（各艇按时扫到自身任务格心的概率之和），以及沿途分数（同一联合样本内对三艇已扫格求并集，再按初始公开信念加权并在样本间求均值）。有效预测前缀只提供下界时保留区间。原分工优先同分；若预测能确认严格改善，选择得分最高的分工。其余平局沿用原生空间增益优先顺序和候选键。
- 每个家族先执行一次空间分工。发令前已固定两模型对每种分工的预测、各自政策选择及唯一配对分支。优先选择能实际交换两个均通过下界的艇的分工，其次考虑其他有公开路线支持的交换。每层内先考虑两模型按区域、再按沿途覆盖推荐的换艇；第 1、3 家族先历史模型，第 2、4 家族先分箱模型。若没有模型推荐当前层中的换艇，仍按空间优先顺序选一条可行分工作为诊断对照。单独标记实际执行了哪个模型的建议、哪些建议没有物理配对。仅有一种分工或参考路径核验失败时只执行空间组。不补抽家族，不按已看到的结果调整顺序。
- 替代回合从同一原始场景和随机种子重新启动，只更换第一次实际下发的搜索分工。发令前核对公开状态、随机状态摘要、模型预测及待命点。物理记录核对四艇初始位置速度、实际下发的三艇指令、判断接令所用的活跃令牌、执行艇指令及两侧仍在探测时的外生目标轨迹摘要。中途换令后的物理步不继续归给最初分工。
- 对既定 16 步配对，分别计算每艇、团队去重覆盖质量和重叠部分的变化。实际团队增益为替代分工的去重质量减空间分工的去重质量。主表比较真实增益的正、负、零与两模型预测区间的方向；区间跨零为未判定。分开报告模型主动推荐的换艇和诊断交换。两模型在同一物理配对上评分，每个家族只算一对。4、8 步和 24、32 步报告实际前缀与随访；模型预测只比较预登记的 16 步。后两个窗口只记录真值。
- 提前发现、碰撞、换令、外部截断分别记录。单艇已观测到的格心命中继续有效。整队出现换令或探测提前结束时，16 步覆盖差记为未知。覆盖按已发令意图评价，实际拒令单列，竞争事实要求双方均接令。若参考问题反复出现，先查路径接口；若物理上可竞争的任务太少，先查任务时域；若路径一致且可达而单艇增益方向反复判断错误，再考虑校准执行分布。

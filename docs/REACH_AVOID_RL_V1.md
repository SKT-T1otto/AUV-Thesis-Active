# 未知地图下的目标条件化安全可达与任务恢复联合学习

本版本是独立算法 `auv.goal_conditioned_reach_avoid.v1`，入口 `cli reach-avoid`。
原D2、B2/B3 repair-v2、旧safe_rl分支及父证据全部保留。任务网络仍为
28D/3D/124D、4智能体、gamma=.95，原奖励、动力学、发现、交接、捕获和整队
碰撞终止协议不变。新增辅助网络有自己的身份，不能装载或重新标记旧权重。
仅使用老地图 `research_config=None`。Linux运行命令直接在Codex中提供。

## 已有问题与研究假设

原D2在开发场景0002/0006的第96/82步发生执行器Search碰撞。规则保护的后续
两场400步没有碰撞但均超时；0006存在大量低速且未到达导航点的样本。由此只能
得出“避碰不足以证明任务恢复”。不能把这些结果写成新RL方法有效的证据。

候选论文问题：部分可观测地图会产生未知、已失效或暂时不可执行的任务目标。
如何根据角色、阶段和运动历史，联合学习目标继续追踪的价值、替代目标与低层残差，
同时保留原始任务完成标准？候选贡献是这个联合决策问题及其可复现实验，
不是“增加一个安全critic”或“增加一个制动规则”本身。

## 两个不同的价值

令z为因果公开历史，g为带类型的局部目标区域，tau_G为首次有效到达，tau_C为
整队首次真实障碍碰撞。辅助价值定义为

`V_RA,h(z,g) = P_pi_g(tau_G <= h and tau_G < tau_C | z,g)`。

这里pi_g表示保持该局部目标条件的残差策略与同一动作投影，不是下一步风险分类器。
高层每步根据这些局部选项价值重选目标；它不是承诺整个回合保持某一个g。
默认h=1..32，对应dt=.2时的0.2..6.4秒，是局部可达时限，不代表400步任务成功概率。
剩余回合到期或阶段改变会截断局部选项；同一物理步发生到达和碰撞时，碰撞优先。
到达先发生后，之后的碰撞不再推翻这个局部首次事件，但真实任务仍会整队终止。

两个critic各自输出逐时限的“到达/碰撞/继续”竞争风险hazard，经softmax与生存概率
累积为两条CDF。每条单调且二者之和不超过1；推理使用较小到达值和较大碰撞值。
TD目标：本步到达为(1,0)，碰撞为(0,1)，到期且无事件为(0,0)，否则取目标策略
下一状态h-1的值。概率不乘gamma；这与折扣碰撞代价含义不同。

另一个输出 `Q_task(z,g,a)` 学原任务回报，唯一回报来自环境最终给出的原奖励均值，
折扣仍为.95。目标为 `r_original + .95 * Q_task(next, next_selected_goal, next_action)`。
这使目标排序同时关注任务收益和可达性，不把“容易停住”当作完成任务。

## 联合目标选择和三维控制

公开候选集含原任务语义目标及已观测自由走廊上的局部替代点。目标具有SEARCH、
STANDBY、CAPTURE、VIA四种类型。已完成的SEARCH/VIA不再作为可选替代点；
有可行且明显改善待命位置的候选时，不允许直接选当前位置待命。
CAPTURE表示公开移动目标周围的区域，安全控制参考点可偏离区域中心；
STANDBY还要求速度足够低。局部到达不会设置环境success或绕过原捕获保持计数。

候选公开几何条件负责排除已知占据、未验证自由走廊和超出局部窗口的点。
`original_goal_admissible=false`不等于“RL证明目标在真实障碍内”：也可能只是
超出4.5m局部窗口或缺乏观测。真实障碍只可事后标注，绝不作为控制器输入。
未知区域内原目标的潜在不可行性通过带历史的价值估计和持续执行结果学习；
不存在从部分观测绝对识别所有隐藏障碍的保证。

在风险预算和可达阈值满足的候选中，选择

`argmax_g [ Q_task(z,g,a_g) + beta*V_RA,H(z,g) - lambda*P_collision_first,H(z,g) ]`。

没有价值条件合格者时显式退回共同规则候选，不能把未校准价值当成安全证书。
actor输入由360D公开历史和19D目标编码组成，输出3D控制残差。
共享actor为379-128-128-3；双critic为382-128-128-97。辅助网络不替换原任务网络。

执行动作是 `project(base(z,g)+delta_actor(z,g), public_action_library(z))`。
每个公开状态的16个动作由8个候选基础动作、制动、已有buffer退出和6个轴向探针组成，
只依赖公开状态，不依赖网络权重。逐动作检查沿用父版本有限运动/制动检查与速度预算。
库、掩码及真实执行动作都进入回放。TD目标使用目标actor与同一库、同一投影，
避免把被过滤前的动作当成实际行为学习。actor前向值使用投影动作，梯度用明确的
straight-through近似；不声称这是严格可微投影或具有收敛/安全证明。

actor同时提高局部可达价值与原任务价值，降低首次碰撞价值并减小投影偏差；
lambda按风险预算更新。目标排序和控制残差使用共同价值网络，形成广义策略迭代。
候选提议仍为确定性公开几何模块，学习发生在价值、候选排序和残差，而不是声称
整个地图/候选生成过程都由RL学习。

## 观测、目标语义与公平对照

每帧90D包含公开位置速度、估计流场、角色阶段、语义方向、团队相对状态、26方向
障碍证据、局部地图比例、时间、公开动力学参数和实际控制历史，共4帧。
这只是公开历史的有限近似，不能据此声称具有严格Markov充分性。对偶项使用采样训练
状态上的平均风险更新，不等同于已证明满足真实回合碰撞率约束。
公开地图来自既有快照，障碍证据来自既有传感事件，不额外扫描或刷新规划器。
不使用原28D中的真值目标距离；原28D预测拦截点也不冒充目标位置。

新增只读 `MissionCoreEnv.get_public_delivered_target()` 仅返回已提交交接载荷。
发现但尚未交接时不向执行器暴露目标。使用该载荷时间戳、公开运动模型和已观测
占据格重建目标估计；已知地图反射预测失败有显式fallback标记。原始任务协议不变。

基础控制在此独立分支增加公开流场补偿和移动区域速度前馈。规则与学习组完全共用，
原D2不变。原0006的PD流场平衡以及.25m跟踪点阈值不能成为RL优越性的混杂因素。
到达区域统一使用.75m（捕获.8m），不是为某一个学习组单独降低任务标准。

## 数据与身份

手动collect只接受独立train/train场景。nominal采集原D2零残差事实轨迹；explore使用
共同公开保护与随机局部选项，mixed交替二者。新NPZ记录公开历史、地图掩码、候选、
动作库、真实物理后动作、原奖励、真实整队碰撞与终止；每文件哈希绑定。

少量未来已实现区域可以做hindsight辅助事件重标记。它只监督几何首次事件，
绝不能把某个已执行目标的原任务回报复制给另一个目标。任务Q仅对事实选项训练。
碰撞、成功到达、其他样本分池保留，分层采样权重纠正到保留缓冲区分布。
这纠正采样比例，不代表概率已经校准。训练前必须保留到达和碰撞支持、足够样本
及明确预训练更新预算；缺失支持时直接拒绝启动新训练。

新权重侧车记录算法、源身份、选项、训练场景和物理指纹。评估先核验身份、哈希
与训练/评估分离，再读取新权重；不支持训练恢复。旧safe_rl学习入口仍保持暂停。
自动验证不加载任何权重文件，不启动研究训练；只允许临时合成样本的4次辅助更新。

## 实验怎样检验论文主张

先在老地图独立训练集收集数据和训练；开发0002/0006只做复现与调试，不能作为训练集。
另行冻结未用于调参的测试场景和随机种子。至少比较：

| 组 | 作用 |
| --- | --- |
| 原D2 ZERO | 保留原问题与原回报参照 |
| 同基础控制+公开动作投影+规则选点 | 隔离纯安全过滤/规则恢复能做到什么 |
| `safety_only`独立训练 | 同网络规模，移除可达阈值和可达actor项/排序奖励 |
| `no_goal_repair`独立训练 | 保留残差与保护，只允许原目标 |
| `full`独立训练 | 完整价值引导目标修复与控制联合学习 |
| full权重上的`zero_residual`/`no_goal_repair`干预 | 测试同一权重具体依赖哪个模块，明确不是重新训练的消融 |

保持相同场景、任务奖励、传感预算、动力学、训练步数和随机种子。报告全部阶段/全部
角色碰撞、任务成功、超时、发现到成功时间、移动/停滞、真实目标恢复率、错误目标
识别的提前量和误拒率、可达价值Brier/可靠性曲线、投影比例及耗时。绝不能只报
Search碰撞下降；必须区分避免碰撞、推迟碰撞、转移到Intercept、停住直到超时。
非法目标测试应同时包含搜索者与执行器，并混入正常可达、仅远距离、动态被阻断
目标，防止“拒绝所有目标”的方法获得虚假优势。真实AABB只供离线分层与评分。

候选假设是：完整组在同等安全保护下，比规则和risk-only组取得更高的任务恢复/成功率，
且不以增加总碰撞或无进展超时为代价。未完成独立实验前，不能写成已证明优于过滤。

## 相关工作边界

[UVFA](https://proceedings.mlr.press/v37/schaul15.html)已经研究状态与目标共同条件化的价值；
[HER](https://arxiv.org/abs/1707.01495)已经研究事后目标重标记。
[Recovery RL](https://arxiv.org/abs/2010.15920)使用离线约束数据和独立恢复策略；
[Back to Base, L4DC 2025](https://proceedings.mlr.press/v283/begzadic25a.html)已经使用
reach-avoid价值构造安全返回过滤器。上述组件本身不能声称首次提出。本项目拟研究的
差异是未知地图、错误任务目标、异构搜索/执行阶段下的目标选择与控制联合恢复。
这只是候选论文贡献，仍需更系统文献比较和完整消融实验确认。

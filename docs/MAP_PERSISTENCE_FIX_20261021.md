# 新地图持续运行修复：coupled_search_v2

2026-10-21 用户明确要求修复新地图故障，保证持续参与，而非仅成功提案一次。
这是一项明确的地图算法版本演进；不改变 B2/B3、4 智能体、28D/3D/124D、
gamma=.95、原奖励、优化器、训练更新节奏、环境动力学、发现/交接/终止合同。

## 问题与修复

旧版用最多 8 个空间命中簇生成随机 AABB，要求其同时解释所有历史射线。
空间簇并非障碍物数；随历史增长，聚类超限会阻断恢复。有限的三个地图也会被
新扫描同时淘汰，随后随机重建耗尽。末尾错误覆盖了首次失效原因。

新版只从公开扫描构造有体积的 AABB 表面支持：每个不同命中都必须被解释，
每次添加和合并都检查全部保留的自由射线区间。merge_neighbors=8 仅限制一次
合并时搜索多少邻居，不再丢弃第 9 个及之后的命中。额外未知障碍补全只能放在
公开射线允许的位置。该几何是声明的近似补全先验，不能当作隐藏真实障碍的
精确重建；支持厚度和连接方式改变了地图假设，需要重新做性能实验。

新观测清空当前地图支持时，同一次消费事务内重新构建地图、重新生成初始目标
粒子并重放完整公开历史。重建失败会恢复此前完整状态，不留下半重放状态。
不删除负证据，不给不一致地图添加似然下限，不把空地图当成成功恢复。

为控制完整历史恢复成本，目标粒子的无碰撞直线运动使用批处理；只要可能接触
世界边界或膨胀 AABB，就调用未改动的原标量反射积分器。分别核对无碰撞、
边界、障碍物、多步反射结果。真实环境仍使用原物理函数。

## 持续参与合同

- 每个搜索观测批次记录 search_batches / available_search_batches /
  unavailable_search_batches。有效意味着联合信念已更新到当前物理步，
  不能仅检查一个残留 valid 标志。
- 同步恢复后仍不可用、公共事件无效或历史丢失时，明确抛错并保留诊断；
  不允许静默转入 D2 后发布“成功完成”的研究回合。
- 搜索阶段每步用当前联合信念和执行误差情景重新评分已安装路线；候选重规划
  仍遵守原事件、冷却和安全稳定化。没有事件不强迫换路线。
- 逐步记录 core_scored_steps / last_core_scored_step。回合发布要求全部
  搜索批次有效，且除初始化外每个搜索决策步都完成新评分。
- 找到目标后按原合同冻结搜索、交接和执行；此时不要求继续生成搜索假设。
  安全层的必要路线替换和候选规划回退仍保留并计数，不伪称“永不失败”。
- 任意输入、计算预算下永远成功无法保证；本版保证不可用时可见失败、不能被
  一次提案或最后状态正常掩盖。完整运行的指标还需 Linux 独立确认。

coupled_search_v2，几何 prior_id 为 public_ray_constrained_aabb_support_v2。
现有 Python 包目录和配置文件名为兼容入口保留，文件内容显式携带 v2 身份。
旧 core-v1 配置不被静默接受。

修复前 471 个源码/证据/交付文件冻结在
provenance/baselines/map_convergence_20261021_v1/，旧 manifests 和
verification/map_convergence_v1/ 均保持原样。新版本必须生成自己的检查、
Linux validation、RUN 和权重；不能继续使用 207fd35 的验收或重标旧检查点。

仍为 4 个 RL 组 × 2 个种子 × 300 ep。先前 generator_seed=827399 的固定
验证场景已经用于定位故障，现作为开发回归输入保存在
configs/map_persistence_cases.json。新版验证生成 seed 改为 827499；
最终测试生成 seed 仍为 92729，不能按其分数选检查点。

## 验证要求

纯数据检查包含：超过 8 个命中簇、全部历史命中/自由射线、矛盾证据明确失败、
重建失败原子性、原积分器数值对照、400 步连续公开观测与周期预测、
不可用时中止、发现后按原合同停止搜索。

Linux 的 tools.check_map_training 不再只检查 core_proposals>=1。
机制流程仍为 8 个回合、每回合最多 32 步、最多 256 个物理步：
4 个临时模型各训练 1 回合并原生评估 1 回合，直接使用内存模型，不恢复文件。
训练夹具 batch=4、warmup=16、update_frequency=16、每次两轮，单模型总计四轮
完整多智能体更新；这些仅是临时夹具，正式学习配置不变。
NEW 的长搜索训练夹具须在第 24 步以后仍完成评分；训练和评估均要求搜索批次
全部有效、零不可用批次、逐步评分完整。评估若提前发现目标，就核对发现前的
全部搜索步，并按原合同停止搜索，不为了凑晚期评分次数而更改发现/冻结语义。
失败就不生成通过的验收。

短程机制检查和合成 400 步观测检查都不证明完整 400 步闭环性能或 RL 收敛。
本轮不自动启动长训练，不恢复已有权重，也不自动提交/推送。

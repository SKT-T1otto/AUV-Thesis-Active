## 耦合信念

每个持续地图 M_r 保留 alpha_r，以及各自的目标位置、速度和条件权重 omega_rn。目标运动直接调用原 advance_target_state，使用该假设地图。每个新公开事务只处理一次；第 0 步扫描不算未发现，严格碰撞早退不算负证据，超时前已完成的发现检查仍有效。

实际未发现时，以三搜索器和假设目标在同一步的 swept relative distance 计算 L_N。随后严格执行：

    raw_rn = omega_rn * L_N(r,n)
    Z_r = sum_n raw_rn
    alpha'_r ∝ alpha_r * L_M(r) * Z_r
    omega'_rn = raw_rn / Z_r

零条件质量对应零地图质量，不用漏检下限掩盖全部退化。补充地图时重新生成初始目标粒子并重放全部公开历史；不会更换地图却沿用旧目标状态。历史被截断、地图不兼容、总质量为零、反射失败或预算耗尽都有明确错误和 D2 回退记录。当前保留加权粒子并报告 ESS，未加入隐式目标重采样。

## 发现签名、压缩和团队评分

同次规划共享一批带联合权重的目标轨迹和执行情景，不为各候选独立抽样。签名为首次未来发现时刻 T 的 exp(-beta*dt*T)，未发现为 0；未来从第 1 步开始。团队按每条目标轨迹上的最大签名计分，多艇/多次覆盖不会重复累计。未折扣发现概率另行保存，不把带成本的目标值当概率。

压缩距离为 max_e sum_l w_l |f_a-f_b| + lambda_cost |C_a-C_b|。按最远代表逐次选取，强制保留当前可行参考路线；达到候选上限时记录实际 epsilon 和 reached_error_target=false，不伪报阈值达标。

团队目标为 (1-rho)*执行情景加权均值 + rho*最坏情景效用 - lambda_cost*总路线成本。每艇默认最多 4 个代表，三艇最多枚举 64 个组合；实际组合数随压缩结果减少。部分重规划把其他艇的实际路线固定为单一选项。参考路径不会被重新求出的最短路替换；完成前缀不重复收费，剩余段沿用原图边成本和原连续端点成本公式。

## 执行不确定性

预测复制原零残差先验控制、逐轴加速度限幅、先加速再阻力的顺序、浮力、水平/垂直速度限制、积分和边界处理；同时复制 PathTracker 的有序子目标推进规则，并从实际 tracker 游标续算参考路线。

过去公开起终位置/速度与上一安装 tracking target 用于估计总执行速度误差。情景包含名义零误差以及保留跨艇相关性、连续时间顺序的误差块；所有候选共用这些情景。该误差同时含控制残差、扰动和建模误差，不能声称已识别真实海流，也未预测未来 Actor 动作。

安全是硬约束：公开几何中不安全的预测段被截断，其后没有发现收益；已 Hold 的路线收益为零。实际安装路径/终点与预测不一致时使预测失效，禁止把被安全桥替换的路径继续计作原方案执行。审计中的独立重采样只针对同一有限目标库，不是独立真实场景评估。

## 配置和入口

configs/coupled_search_v1.json 继续是旧 observe_only 接口配置。新 configs/coupled_search_core_v1.json 使用 ch3.coupled_search.core.v1，默认 enabled=false。默认开发规模为 3 个地图、每图 32 个粒子、16 步时域、3 个执行情景、每艇最多 12 条原始路线/4 个代表、72 次路径查询。推断/规划各有独立时限，历史有上限；这些数值是声明的开发配置，尚未按实验调优。

核心可通过 RepairedMissionRuntime(..., map_research=<显式开启的完整 core 配置>) 使用；B2/B3 方法本身未重定义。目前提供的公开命令仍只做零残差机制审计：

    python -m chapter3_bser.experiments.coupled_search_v1.reference --config configs/b2_mechanism.json --interface-config <显式开启的core配置.json> --manifest <机制eval_manifest.json> --output <新的Active/work机制输出目录>

该命令不带 --execute 只打印计划。显式执行仍受最多 8 回合、每回合 32 步和总计 256 步约束，不训练、不读取模型文件。tools.check_coupled_search 另提供至多 3 个夹具回合的开发核验。输出目录必须新建，不覆盖历史结果。

# OLD地图上的路径条件option学习 v1

这是独立候选算法 `auv.path_conditioned_options.v1`，不是D2/B2/B3或旧Reach-Avoid的改名。
原始核心、奖励、动力学、目标过程和碰撞协议不变。只有辅助策略、目标管理和执行指导改变。
没有正式性能结论，没有数学收敛或安全保证。

## 算法与边界

- 四智能体共享辅助策略，使用角色、阶段和已有共享公开规划状态；不是严格分散执行的声明。
- 原任务网络28D/3D/124D保持；辅助网络读取16×90历史、19维任务/路径目标描述和13维有序路径点。
- 默认64维、2层、4头因果历史编码。运动历史与目标表示作为路径cross-attention查询。
  固定query版本和相同原始输入的MLP版本均可实际运行。MLP对逐点编码作带掩码聚合，
  每个点包含弧长和顺序；不同归纳偏置和参数量均应报告，不声称严格容量相等。
- 保留全部剩余路径顶点，批处理只padding，不将注意力坐标平均成导航点。
- 公开路径查询使用EndpointView、extract_planning_state和TravelCostService；不刷新决策图。
  目标到达后的任务请求是显式行为事件，可以刷新D2；诊断不触发刷新。
- 原始D2建议、承诺任务、恢复端点、路径及跟踪点分别记录。上游每次更新不自动改变承诺。
  搜索区域完成采用“到达公开有效端点”的代理条件，并请求D2重新分配；不声称整个区域已穷尽。
  执行器到达待命区后保持；交接后按公开目标预测更新移动区域。
- 无路线或已知占据目标触发恢复；未知远目标不被当作已知安全，也不因32步不能到达而被否决。
- 候选含D2建议、路径推进点、方向性绕行和公开自由/未知格。最多14个端点查询/体/轮，
  查询间隔默认10步；候选路线可能有观测延迟，特征公开查询年龄，底层动作仍逐步检查。
  恢复候选预计执行时间默认2—30秒，使用D2路线时间加公开制动估计；原承诺远任务不因超出此范围被否决。
  粗格起点无效时，每个端点最多检查4个公开自由起点连接，连接段必须经细化公开射线验证；
  不改变原地图、物理位置或碰撞条件。无可行候选时不重复产生目标终止，按查询间隔等待新证据。
- 八个跟踪先验动作、制动、缓冲退出、六轴探测构成共同16动作库。
  策略根据实际三维候选向量打分，不能依赖固定索引的物理语义。
  本版不是任意连续残差学习，没有最近邻直通梯度。
  训练与冻结评估均执行同一个categorical策略，评估使用冻结配对随机种子；不在推理时偷偷改成argmax。
- 执行安全覆盖或物理掩码改变动作时，不对该动作使用自主低层策略损失；critic用实际动作。
  所有主要消融共享动作库及安全检查。安全层不是已认证控制屏障。
- 同一承诺期间路径重规划不等于任务切换。路径进度只因到达航点前进，不因地图计数增加归零。

## 学习定义

任务critic Q(z,g,a)使用原team_mean奖励。QΩ为当前掩码动作策略下Q的期望。
终止后的VΩ为候选目标策略下QΩ的期望。逐物理步目标为：

`y = r + .95*(1-done)*[(1-beta)*QΩ(next,current) + beta*VΩ(next)]`

没有再乘gamma的持续步数。终止损失为 `beta*(QΩ(current)-VΩ)`，只在允许学习终止时更新。
候选动作策略使用枚举动作的期望价值，目标选择策略在决策边界学习。
安全可达头的到达收益和碰撞风险参与低层及目标选择，beta也接收这两个预测作条件。
任务终止优势依旧来自原奖励；没有新换点奖励或停滞惩罚。
双critic采用保守任务值、到达值和风险组合；这是近似共享策略off-policy学习，
不声称拥有严格多智能体策略改进定理或完整联合动作CTDE critic。

安全可达头是32步竞争事件：到达、碰撞、继续；概率不乘.95。
评价区域是本转移开始时固定的近期跟踪区域，下一状态以同一个事件查询区域计算目标，
不能将新航点的到达当作旧航点标签。碰撞优先于同时到达；阶段结束、任务终止和
环境时限使剩余事件时域到期。到达要求公开自由及间距，待命/接近阶段还要求速度条件。
移动区域只使用收到的公开目标估计，不读取真实未来位置。

回放为统一的factual uniform replay，不使用旧版本分层回放或hindsight。
这是本独立算法明确的训练设置变化，所有新对照保持一致；二者不列为本轮贡献。
仅实际执行的目标获得原任务奖励，不给未执行替代目标复制奖励。
所有训练从零开始，无离线预训练、无bootstrap回合、无训练恢复入口。
权重文件只用于来源匹配后的冻结评估；旧权重不兼容。
搜索器冻结后的实际零动作转移仍用于团队回报critic，避免发现后的价值只能从未训练分支bootstrap；
冻结期不更新自主动作策略，可达事件时域结束。

## 实验矩阵

pilot：A完整、B相同信息MLP、C事件规则终止；各1种子×100ep，最多400步/场，每25ep评估12开发场景。
formal：A/B/C/D无安全可达学习；各3种子×500ep。补充组必须显式--supplemental选择。
所有对照只改变指定功能及其一致的训练目标；共同安全层不删除。
固定最终预算检查点为主结果，不用测试集挑模型；其他检查点只作开发曲线。

正常测试100场，专项5×20场。专项几何和故障输入冻结，覆盖错误目标、必要绕行、新观测阻断、
远目标、转弯制动。它们是“设计的挑战”，必须按trace确认实际遭遇，不能将场景名称当成机制发生证据。
物理目标始终在有效空间，故障只替换控制器收到的任务建议，不更改物理目标。
专项布局离线使用真实几何构造与验证，但运行时只收到普通观测和目标坐标。
先验动力学、流场幅度不改变；本版没有增加初始速度API。

评估干预：no_path、no_history、rule_termination、rule_recovery、rule_action。
明确为inference_intervention，不能称作重训消融。
原D2正常任务和共同路径/安全层下rule版本无需训练。

主指标为成功、全部阶段碰撞和超时，辅以发现、失败计罚时间、任务切换、终止、停滞、跟踪误差、
恢复步数、强制覆盖、实际执行比例和耗时。原始逐步trace用于恢复后推进与失败归因。
汇总保留未完成任务；配对场景差异与训练种子波动分开，不把100场当100个训练重复。
连续回报或loss平稳不等于收敛。报告经验平台、任务质量和学习更新，不自动追加预算。

事实轨迹预测诊断只在目标/查询不变且有完整事件标签时统计，切换或截断单独计为censored。
没有实现任意中间状态的完整环境续航恢复，所以不声称策略反事实概率已校准。

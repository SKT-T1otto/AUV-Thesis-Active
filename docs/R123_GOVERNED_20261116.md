# 限速一致的动作基准修正

用户要求在Windows修正并推送，由用户在Linux运行。独立包 `chapter3_bser/r123_governed` 保留旧代码、清单及实验结果。仅使用去恢复生命周期，不增加网络、奖励或恢复分支。

基准先使用现有安全速度上限生成，再考虑公开目标速度、估计流场与浮力；用同一公开离散动力学计算下一步速度，投影至现有上限后反解加速度，最终仍受原物理加速度限制。若当前超速且无法一步减至上限，不伪造瞬时停止，保留原逐步降低超限量的准入规则。基准周围仍是六个±0.15归一化加速度残差，所有动作仍通过原速度与几何/备份检查。没有放松任何阈值或改变环境物理、任务奖励、成功判据和地图。

零限速或几何拒绝不能强行导航。远离端点而仅剩零运动候选时，明确保留刹车并记强制兜底；到达待命位置的正常悬停不算导航被阻塞。模型检查全失败时仍标记emergency，不能把最后兜底冒充验证通过。

每个实际选择路径增加action_diagnostics：安全速度上限、可用距离、原名义动作、受限基准、候选mask、每个候选的速度/几何/备份拒绝原因、是否有普通导航候选、验证退出和emergency。另存最终部署mask与实际动作索引。未提供普通导航选择的刹车不再记为无强制的策略执行。

对照只比较旧no_recovery与新governed，主动恢复均关闭。原六场景、配置、随机种子982001+n保持一致，旧结果只读导入，不重新跑。报告比较成功、发现、碰撞、超时、步数、等待、实际静止、低速未到端点及刹车次数。旧结果没有新增诊断字段，不能把诊断缺失解释为没有拒绝。

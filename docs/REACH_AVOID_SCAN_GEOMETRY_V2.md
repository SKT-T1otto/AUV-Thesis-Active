# 公开扫描细化局部运动几何

本修订以806635e为不可变父版本，仅修正独立reach-avoid分支的局部几何。原D2、B2/B3 repair-v2、旧safe_rl分支、4智能体、28D/3D/124D、原奖励、动力学及任务终止语义保留。辅助RL网络维度、优化器、gamma=.95和学习目标均未改变。

## 碰撞与制动

真实碰撞仍由`core/env/uav_env.py`调用`closed_segment_aabb_first_hit`，对本步运动线段与真实障碍AABB作闭集合求交，接触表面也算；命中即整队失败。同一个地图网格并不构成碰撞。

父版本0006没有伪造碰撞事件，而是公开占据格包围了实际未接触障碍的当前位置，导致动作检查全拒绝、连续制动，最终超时。本次修正针对这种误停，仍允许传感器证据或制动距离不足时主动刹车。制动、超时、真实碰撞继续分别记录。

## 具体修改

新增`chapter3_bser/reach_avoid/scan_geometry.py`。公开扫描自由段按0.25米子格细分，障碍命中子格优先于自由证据；只在本回合内缓存，适用于当前OLD静态障碍任务。传感器和粗地图本身不变，没有新增真值访问。

射线恰好位于子格面或棱上时，采用闭网格supercover，记录所有接触到的相邻子格，避免仅记录单侧而错误拒绝受扰动后的近障退出。命中子格的优先级和命中点保护距离保持不变。

全局规划及候选目标的粗格风险过滤保持不变。局部运动遇到粗占据格及其膨胀区域时，每一段都必须有细分扫描自由证据才能通过；没有扫描依据的部分仍被拒绝。不会把当前整个粗格清空。每段运动按子格面切分，并检查中间段和端点，不能仅凭两个端点有自由证据就穿过未知部分。

局部速度距离和方向特征不再使用已被细分自由证据解释的粗格最近点作为“零距离实体表面”。实际扫描命中点的0.4+0.12米保护距离、流场补偿、有限运动及制动检查继续生效。退出动作沿用原方向、扰动角点和制动条件，额外检查整个预测通道的细分证据。

若起点和近距离命中点恰在同一细分格，普通运动仍被拒绝。单独的退出分支可以离开这个初始混合子格，但必须同时通过朝外支持平面、每个扰动角点的首步向外运动和后续制动检查；其余子格仍需扫描自由证据。这个例外不会用于普通前进，也不会清空整格。

辅助目标到达事件使用同一份局部位置自由标志；该4维布尔量随数据集保存与读取，保证在线事件与回放标签一致。原任务的发现、交接、捕获和成功仍只由原环境决定。原粗格掩码仍原样保留在回放中，未伪装成全局自由地图。

规则与学习比较组共用此动作域。actor/critic网络维度不变，新来源身份拒绝旧来源权重和数据的重新标记。

## 日志与验证范围

逐步trace增加`local_geometry`，记录粗格是否包围当前位置、细分自由证据、子格分辨率等；`stop_cause`区分检查通过的制动与没有检查通过动作的紧急制动。两者都不能冒充真实碰撞。

`checks/fixtures/reach_avoid_0006_public_scans.json.gz`是从用户已完成的806635e规则运行离线重建出的公开扫描与公开状态，包含三个冻结时刻，不含真实障碍几何。其重建经过父版本4800项决定核对，零不一致。工具`tools.check_scan_geometry`检验执行器step=80、搜索器0 step=171、搜索器1 step=267是否恢复检查通过的运动候选。

另有`checks/fixtures/reach_avoid_buffer_public_scan.json`，仅保存原四智能体近障压力场景的初始公开扫描与公开状态，检验新几何是否保留可检查的向外退出动作；它也不含真实障碍几何，不代表32步环境运行通过。

该检查不创建环境、不推进物理步、不训练或恢复权重。预测的一步位移和任务距离变化只是冻结状态下的模型结果，不是新的轨迹或成功率。连续射线采样和子格离散化仍是近似，不能宣称连续空间安全认证。

本轮自动验证只运行无环境回归、源码审计和冻结状态检查；不重复先前已经用完的8次自动初始化预算。当前修订尚需用户在Linux显式执行新来源的短步验证，之后再人工运行0002/0006完整对照。父版本8例/232物理步不属于当前修订的环境验证。

本修改解决动作域的粗格误停接口，不作为RL创新或论文性能增益的证据。有效性仍须用真实碰撞率、原任务成功率、超时及持续停滞共同评估。

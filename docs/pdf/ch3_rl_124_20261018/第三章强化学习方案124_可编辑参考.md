## 6. 共同基础：完整状态、公共输入与目标值
*数学依据 / 全部方案共用*

令 S_t 为完整模拟器状态，包含物理状态、隐藏目标、地图、规划器、交接队列与随机数等；X_t=(o_1,…,o_4) 为 Critic 的公共联合输入。S_t 可以作为训练仿真的恢复依据，但不能输入部署 Actor。

Q^(π)(S,u) = E[∑_(k=0)^(T-1) γ^(k) r_(t+k) | S_(t)=S, u_(t)=u, π thereafter]

q^(π)(X,u) = E[Q^(π)(S,u) | X_(t)=X]

式 (3) 是完整状态下、当前动作固定、未来恢复同一策略 π 的动作价值。式 (4) 是在某一明确状态分布下的条件平均；X 未必满足马尔可夫性，分布随策略变化也会改变。因此本文不为 124D 网络宣称精确 Bellman 收缩或全局收敛。

### 合法干预与目标策略冻结

动作候选只使用公共 X、允许的动作边界和固定采样规则。每组分支恢复同一 S，仅当前步动作不同，下一步起由一个版本固定的目标策略 π̄ 及原规划器正常闭环运行。标签不反传梯度；记录策略哈希与标签生成时刻。

V_(tar)(X) = min{Q_(tar,1)(X, μ_(tar)(X)), Q_(tar,2)(X, μ_(tar)(X))}

下标 tar 表示冻结目标网络，等价于文中带横线的记号。式 (5) 对每个现有智能体的双 Critic 分别计算；团队奖励相同不意味着要合成新网络。若选择 B3，目标策略的上下文构造也必须按其原接口执行。

**同世界配对的价值**
相同状态和合法随机数耦合能减少场景差异带来的混淆，但不保证方差必降：Var(Y+ - Y-) = Var(Y+) + Var(Y-) - 2Cov(Y+,Y-)。随机流耦合须保持每支正确边际分布，分支事件导致随机调用次序改变时尤其需要检查。

## 7. 方案 1：用真实动作后果校准价值差
*原编号 1 / 原理与目标*

### 要解决的具体问题

普通一步 TD 主要约束 Q 的绝对值。有限样本和函数逼近下，两个邻近合法动作的误差可能方向相反，使 Critic 对“更能保持接触”或“更可能碰撞”的动作给出错误排序。新增监督应直接来自实际闭环后果，而非另加一个事件预测头。

u^(±) = clip_([-1,1])(u^(0) ± εd),   u^(0)=μ_(tar)(X)

Y^(b) = ∑_(k=0)^(h_b-1) γ^(k) r_(t+k)^(b) + γ^(h_b)(1-d_(b)) V_(tar)(X_(t+h_b)^(b))

ΔQ_(φ) = Q_(φ)(X,u^(+)) - Q_(φ)(X,u^(-)),   ΔY=Y^(+)-Y^(-)

L_(Q) = L_(TD) + λ_(Δ) E[w (ΔQ_(φ) - stopgrad(ΔY))^(2)]

h_b 为预先定义的有限时域或停止时刻；d_b 只表示真正终止。初版可先用 h=1 且沿用原目标裁剪得到严格对齐的目标；多步式 (7) 与现有裁剪语义的关系见第 16-18 页。不能忽略该问题直接替换。

### 为什么可能改善学习

同一状态下的差分削弱了共同价值偏移，训练重点转向 Actor 真正需要区分的动作效应。跨事件的有限动作对还可暴露单点平滑梯度看不到的阈值后果。不过，这只是有依据的假设：跨阈值的割线并不是该点真实导数。

建议先验证执行者接触、保持中断与碰撞，再验证搜索残差对发现时间的间接影响。若每次只改变一步就几乎不影响后果，该方向应停止或重新定义研究对象，不能暗中改成动作段控制。

## 8. 方案 1：它增加的是误差方向约束
*原编号 1 / 损失解释与 Actor 联系*

令同一批两个分支的预测残差为 e+=Q+ - Y+、e-=Q- - Y-。先用平方损失说明机制，实际代码原 TD 为 SmoothL1；二者不能在论证时混为一谈。

L = e_(+)^(2) + e_(-)^(2) + λ_(Δ)(e_(+)-e_(-))^(2)

L = (1+2λ_(Δ)) z_(diff)^(2) + z_(mean)^(2)

其中 z_diff=(e+ - e-)/√2，z_mean=(e+ + e-)/√2。差异方向权重变大，共同偏移方向不变。若两个分支 TD 误差本来都为零，新约束也为零；它并未创造新的零误差固定点。

∇_(φ)L_(Δ) = 2λ_(Δ)(ΔQ-ΔY)[∇_(φ)Q(X,u^(+))-∇_(φ)Q(X,u^(-))]

### Actor 初版保持现有更新

∇_(θ_i)J ≈ E[∇_(u_i)Q_(φ_i,1)(X,u) ∇_(θ_i)μ_(i)(o_(i))]

其他智能体动作继续按原实现停止梯度。方案的因果链是“动作效应标签更准确 → 原 Q 的相关动作几何更可靠 → 原 Actor 更新更有效”，每个箭头都需要证据。有限差分误差变小不能保证 Actor 处导数正确，也不能推出单调策略改进。

**必需的相同数据对照**
比较同样的 S、u+、u-、Y+、Y-：仅分支 TD vs 分支 TD + 差分损失，并控制优化步数及采样权重。否则收益可能全部来自额外仿真数据。对原 SmoothL1 的损失保持原实现；差分项先用平方损失，稳健 Huber 作为单独消融。

### 避免动作饱和与样本选择制造假信号

u+ 与 u- 限幅后可能相同；物理先验叠加限幅后又可能相同。日志应分别给出归一化动作不同率、物理动作不同率、轨迹不同率和事件不同率。不得为了产生事件而放大残差上限。发现后被冻结的搜索者可提供“真实零效应”负对照。

主实验从自然训练占用分布抽样，记录不成功与同事件分支。边界压力集可额外评估，但不能仅保留隐藏真值显示“恰好跨阈值”的成功样本。若采用已知分层概率 q_s，目标占比为 p_s，可使用 w=p_s/q_s；截断权重会引入偏差，必须披露。

**独立性**
确定性环境中，同一 S、相同动作、相同策略重复四次会得到同一标签；这不是四个独立观测。随机置信区间应来自不同合法世界/回合，或任务本身真实存在的随机性，不能为制造重复而改变目标策略。

## 10. 方案 1：具体落地与诊断输出
*原编号 1 / 实施步骤*

### 最小算法流程

```text
1  Sample a valid decision state S and public input X.
2  Freeze target-policy / target-critic version v.
3  Propose u_plus, u_minus from X; save proposal probability.
4  For each branch: restore S; intervene for ONE step.
5  Continue the original closed loop under frozen policy v.
6  Build Y_plus, Y_minus using one declared label protocol.
7  Fit both existing critics with TD and paired contrast loss.
8  Update the original actor on natural replay observations.
9  Audit held-out contrasts and actual policy returns.
```

Actor 更新初版仍从原训练回放取公共观测；分支缓存只用于 Critic，避免同时改变 Actor 的状态分布。分支的当前动作可以偏离目标策略，当前动作之后的后缀必须跟随已冻结策略；这是 Q(S,u) 的语义，不是全程 on-policy 要求。

| --- | --- |
| contrast_rmse / tie-aware sign_accuracy | 检查动作差分预测；在标签接近零或噪声带内不强行计正负。 |
| physical_action_distinct / event_change_rate | 检查残差是否真的有控制权限。 |
| bootstrap_mass / clip_rate / policy_version_age | 检查收益是否由不可靠尾值、裁剪或陈旧标签驱动。 |
| actor_step_return_delta | 小步 Actor 更新前后在配对场景的真实后缀收益变化；这是诊断而非额外策略搜索。 |
| branch_steps / restore_time / critic_steps | 完整披露训练额外计算。 |

**方案 1 的立项判断**
仅当合法一步残差存在有意义后果、原 Critic 对这些后果估计失准，而且相同数据/预算下差分监督优于仅 TD，才值得进入较长训练。若只改善排序而不能改善最终控制，应按机制负结果记录。

## 11. 方案 2：四次干预识别非加性共同作用
*原编号 2 / 原理与公式*

两个智能体都改变动作时，团队收益变化未必等于两个单独改变之和。例如多个搜索者对同一发现机会产生重复作用，或者搜索者提前发现与执行者接管位置共同影响后续完成时间。是否存在这种现象必须实测。

u^(ab) = (u_(i)^(a), u_(j)^(b), u_(-ij)^(0)),   a,b ∈ {0,1}

I_(ij)^(Y) = Y^(11) - Y^(10) - Y^(01) + Y^(00)

I_(ij)^(Q) = Q(X,u^(11))-Q(X,u^(10))-Q(X,u^(01))+Q(X,u^(00))

L_(Q) = L_(TD) + λ_(I) E[w (I_(ij)^(Q) - stopgrad(I_(ij)^(Y)))^(2)]

| 解析例子 | (Y00,Y10,Y01,Y11) | I 的含义 |
| --- | --- | --- |
| 加性收益 | (0,1,1,2) | 0：没有该二阶共同作用 |
| AND 共同成功 | (0,0,0,1) | +1：单独改变无效、共同改变有效 |
| OR 重复成功 | (0,1,1,1) | -1：两个改变争取到同一份收益 |

I 是对原团队回报的差中差，不是新奖励，也不是每个智能体的 Shapley 值。正负都可能合理，不能强制“协同项为正”。这也不是把原 Q 分解成单体与两两 payoff 网络。

与 DCG [8]、COIN [9] 的实质区别在训练信号来源与参数化：使用真实四支闭环后果监督现有集中标量 Q，不引入图结构、个体-全局多目标或交互预测头。该区别仍需证明有用，数学差中差本身并不新。

## 12. 方案 2：在当前任务中，什么交互值得测
*原编号 2 / 阶段与候选选择*

## 13. 方案 2：损失为什么可能改善联合价值
*原编号 2 / 推导、成本与局限*

将四个分支的误差按 (00,10,01,11) 排列为 e，令 c=(1,-1,-1,1)。二阶损失只强化“联合改变相对于单独改变”的误差方向。

L_(I) = λ_(I)(c^(T)e)^(2),   c=(1,-1,-1,1)^(T)

L = e^(T)(I_(4) + λ_(I)cc^(T))e

平方 TD 例子中该误差度量有一个特征值 1+4λ_I，其余三个为 1。它加强一个交互方向，保留其他方向；不是新增独立信息，四支都拟合精确时交互误差自然为零。必须有“四支数据仅 TD”的对照。

### 噪声与可辨识性

Var(I^(Y)) = c^(T)Σc

Σ 是四支回报的联合协方差。共同随机数可能降低也可能增加某些组合的噪声，不能只按单支方差判断。确定性场景没有同状态蒙特卡洛方差，主要问题变为尾值误差、状态抽样与数值恢复误差。

### 与方案 1 的组合应后置

L_(Q) = L_(TD) + λ_(Δ)L_(contrast) + λ_(I)L_(interaction)

先单独评估交互项，再评估组合，避免同时调两个权重造成解释困难。两项分别按组数取平均；不要把同一组的多种对比当作独立样本。若按幅度归一化，尺度只能从训练集冻结估计并在对照中一致使用。

**不能保证的事情**
只校准二阶项不构成完整联合价值分解；三阶作用可能存在。集中 Q 更准确，也不保证局部观测 Actor 能实现任意联合最优动作。本方案不引入联合最优动作教师或额外部署信息。

## 14. 方案 4：在事件处截断，但保留未来价值
*原编号 4 / 停止时间原理*

对完整状态、固定未来策略与合法有界停止时间 τ，折扣回报可按停止时刻分解。这是停止时间/多步 Bellman 思想的直接应用，不是新的 Bellman 定理。本文研究它如何服务于真实控制事件的差分标签。

τ = min{H_(max), inf{k ≥ 1 : E_(t+k)=1}}

Q^(π)(S,u) = E[∑_(k=0)^(τ-1) γ^(k)r_(t+k) + γ^(τ)(1-d_(τ))V^(π)(S_(t+τ))]

条件是状态/历史足够描述过程，停止规则只使用截至当前的信息，并且回报可积。这里 H_max 有限、任务有限，有界性易于控制。但用 V̄(X) 替代精确 Vπ(S) 后会产生近似误差，原 TD 目标裁剪也会改变语义。

| 建议事件 | 检测规则 |
| --- | --- |
| 导航切换 | 比较闭环步骤前后的有效导航目标或分配版本；排除浮点微小漂移。 |
| 发现 / 交接 | 记录原环境和交接状态迁移，不额外提前告知 Actor；通常非终止。 |
| 首次接触 / 保持中断 | 接触由扫掠语义判断；保持由原 full_hold 与计数清零判断。 |
| 碰撞 / 成功 / 任务时限 | 沿用原协议终止及其优先次序；提前终止后不再 env.step。 |

**不要把每个保持计数递增都算作事件**
否则接近目标时每一步 τ=1，方法退化为一步备份。保持开始、保持中断和任务成功应分别记录；事件时域上限是训练标签截断，不等于环境 done。

Retrace [10] 说明普通旧轨迹多步备份需要离策略处理；AHAC [11] 和 Q-chunking [12,13] 已覆盖其他自适应时域机制，不能用“接近事件缩短时域”单独主张主要创新。

## 15. 方案 4：分支应各停各的，还是共同停止
*原编号 4 / 三种协议与实现*

| 协议 | 明确规则 | 优点与代价 |
| --- | --- | --- |
| P_ind：各支首事件 | 各分支使用自己的 τ_b=min(首事件,Hmax)。 | 便宜且易解释；折扣长度不同可能放大共同尾值偏移。 |
| P_fix：共同固定 H | 所有分支走到同一物理步 H，真正终止的分支以吸收态记账。 | 最清楚的对照；可能多做无必要仿真。 |
| P_min：组内首事件 | 组内任一分支首次发生事件时，全组在该物理步停止，上限 Hmax。 | 共同折扣、成本小；可能频繁 τ=1，尚未显现其他分支后果。 |
| P_all：各支均遇首事件 | 记录每支首次事件；全组都已遇事件时停止，或到 Hmax。 | 更充分覆盖分支后果；成本更高，必须正确处理已终止分支。 |

P_min 和 P_all 都可在分支组的联合信息流中在线判断：每一步推进所有未终止分支、更新已发生事件标记，再决定是否停止。随机耦合还须非预见：给定组内过去，各支条件转移仍符合原任务；仅保证边际分布正确还不够。不得事后选择让标签最好看或回报最高的截断点。

### 组内终止分支的记账

一支在第 t_b 步真正终止后，其后奖励为 0、继续价值为 0，不再调用 env.step。共同 h 目标写作先累积到终止、其后零填充。另一支仍正常运行；只保留共同物理时间标尺，不强迫两支相同事件或相同导航。

### 建议比较顺序

先比较 P_ind 与 P_fix；若观察到不同停止时刻的系统误差，再加入 P_min。P_all 留作后续消融。对事件协议，固定时域对照应同时提供相近平均时域版本与同总模拟步预算版本，不能只与 H=1 比。

**折扣按物理步计算**
原 γ=0.95 时，H=5、10、20 的尾值权重约为 0.774、0.599、0.358。不能每遇到一个事件只乘一次 γ，否则优化目标已经改变。

## 16. 共同停止时刻能抵消哪一种标签误差
*原编号 4 / 条件推导*

暂不考虑非线性目标裁剪。设两支均非终止，近似尾值为 V̂_b=V_b+e_b；相对于精确继续价值的差分标签误差为：

ε_(Δ) = γ^(τ+) e_(+) - γ^(τ-) e_(-)

即使两支尾值误差恰好相同 e+=e-=c，不同停止时刻仍留下偏移：

ε_(Δ) = c(γ^(τ+) - γ^(τ-))

共同非终止时刻 h 则有：

ε_(Δ)^(common) = γ^(h)(e_(+)-e_(-))

ε_(I)^(common) = γ^(h)(e_(11)-e_(10)-e_(01)+e_(00))

共同加性偏移可以抵消；四支系数之和为零，同理成立。这是支持“共同物理时刻”对照的一个具体理由。γ=.95、c=1、τ+=2、τ-=10 时，不同停止误差约 0.303763；共同 h 且两支误差相同则为 0。

|ε_(Δ)| ≤ γ^(τ+)|e_(+)| + γ^(τ-)|e_(-)|

**结论的严格边界**
上述抵消要求两支均非终止、尾值误差含有共同偏移，且未受非线性裁剪影响。终止掩码不同、误差不相关、事件后的状态差异很大时不保证抵消。共同 h 也可能增加成本或方差，不能据此宣称总是优于各支停止。

可验证假设：在相同分支上，P_fix/P_min 是否降低相对于完整后缀参考值的 ΔY / IY 误差；同时比较方差、计算步数与最终策略。解析算例不是项目性能证据。

## 18. 多步后缀、离策略与标签陈旧问题
*原编号 4 / 可落地的初版选择*

### 为什么不能直接拼接旧回放

现有回放是单步合同，没有保证连续片段、完整状态快照、行为策略密度及目标策略支持条件。确定性 Actor 加探索噪声不能直接提供 Retrace 所需的可用概率比。把旧行为后缀当作目标策略后缀，会改变标签语义。

ρ_(t) = π(u_(t)|history_(t)) / β(u_(t)|history_(t))

式 (32) 需要明确的随机策略及支持覆盖；确定性目标的 Dirac 分布不能靠写出密度比解决。初版优先从合法状态产生新鲜后缀：当前动作可干预，后续无探索噪声、按冻结目标策略闭环运行。旧前缀只用来恢复当前状态，不当作目标后缀。

### 策略版本与缓存

每个分支组固定目标 Actor/Critic 的版本；生成过程中不软更新该版本。缓存包含策略与目标哈希、生成步数、场景和标签协议。首版缓存只在同一短训练窗口使用；窗口结束丢弃或重建，避免把不同未来策略的 Y 混成同一个 Q 监督。

### 原奖励、完整后果与真正终止

发现、交接通常不是终止，标签必须保留后续接管与保持价值。终止掩码读取原任务结果，不由事件检测器推断。达到 H_max 只是截断；如果环境未终止，尾值仍保留。若为了审计走到原回合末尾，应计入所有真实仿真步。

### C1 的一个可复现候选定义

y_(τ) = C(∑_(k=0)^(τ-1)γ^(k)r_(t+k) + γ^(τ)(1-d_(τ))V_(tar)(X_(t+τ)))

若后续选择此候选，普通采样状态与干预状态的 Critic 标签均按式 (33) 生成；固定 H 与事件 τ 仅改变停止协议。分支 TD 与差分项使用同一组 y，原 replay 可继续服务 Actor。原一步算法保留为独立对照。该定义是新的有限后缀代理目标，裁剪或尾值误差存在时不能宣称等价于原算子。

**当前可实施边界**
快照、事件记录与诊断可以先在第三章独立命名空间完成。C1 多步训练不能与原一步裁剪目标混用后仍声称同一真实 Q。若新标签定义与原目标不一致，应先隔离实验并重新界定优化的代理目标，再评估实际策略收益。

与 Q-chunking [12,13] 的区别：本文当前动作仍是一个 3D 残差，后续由固定策略接管。若持续干预多步，应改称动作序列价值并改变接口；不能继续使用当前单步 Q 的说明。

### 上线训练前必须通过的检查

恢复一致性：相同快照、相同动作序列得到相同位置、地图、知识、交接、导航与奖励；分支执行前后不污染主环境或主随机数流。先 CPU 确定性检查，GPU 差异另设合理容差。

零干预一致性：u+=u- 时 ΔY=0；四支动作重复时 IY=0。交换 +/- 标签应反号；交换智能体 i,j 后交互值不变。

冻结零效应：发现后只改变搜索者动作，真实轨迹与回报不变；Critic 若仍敏感，记录为模型误差。

事件与终止：扫掠接触不等于 full_hold；发现不截断未来奖励；任务终止不 bootstrap；H_max 截断不伪造 done；共同停止的吸收态记账正确。

接口与回归：28D/3D/124D、原 replay、原奖励与 provenance 全部不变；新章节独立测试。若后续涉及共享核心或目标合同演化，应按 AGENTS.md 运行相应完整回归，不能削弱历史校验。

不提交模型、检查点或长输出；不覆盖 outputs 用户保留文件。代码读取哈希随文档附录保存，表示本轮阅读来源，不修改任何冻结 provenance manifest。

### 通过与停止规则

先在开发集估计标签误差/数值容差，预先设定有实际意义的阈值：如对成功率的最小可接受差、接管/保持时间差或统一奖励尺度下的效应下限；不使用跨任务固定的 |I|>0.1。观察效应区间与尾值误差带是否可区分。

**预算诚信**
没有可用检查点时，先用原规划器/零残差策略采集可达状态，再安排经用户明确选择的有界 pilot；不要自动恢复历史 Phase 1C 或启动训练。确定性重复不能当成多个随机种子。这里没有执行上述实验。

### 至少一种强相关算法对照

优先加入 DAWN 风格的基策略数据锚定对照 [7]；若归一化需要改变冻结网络，则只能作为独立研究变体，不修改原网络。PAVE [6] 是另一项相关对照，按论文目标实现并说明连续动作多智能体适配。不要只用弱一步基线来证明“新损失有效”。

不要求一次把全部组跑满。先完成 B0-B3；A2 通过才考虑 B7-B8，C1 目标审查通过才考虑 B4-B6。开发阶段最多保留两种时域和三个权重中的少量组合，预注册选择规则，避免隐形大规模调参。

**两套公平预算都要报**
其一是总原生环境步数（主轨迹 + 分支 + 恢复 + 审计），其二是训练墙钟时间。固定同一更新数可隔离优化量，但无法同时保证墙钟完全相同；采用性能-成本曲线并完整披露。

## 23. 评价指标与统计：最终策略优先
*实验设计 / 指标定义*

SR = (1/N)∑_(n=1)^(N) 1{mission success in scene n}

T_(find,capped)^(mean) = (1/N)∑_(n=1)^(N) min(T_(find,n), T_(max,n))

未发现的场景令 T_find=∞，截断后记为 T_max，不能删除失败后只比较成功回合发现时间。对成功时间同样给出含失败的截断均值，并同时报告成功率；这不是任意缺失数据条件下的无偏生存估计。

| 层次 | 推荐指标与解释 |
| --- | --- |
| 主要任务 | 完整任务成功率、任务总回报；失败含碰撞/超时。预先指定主要指标与实际意义阈值。 |
| 执行控制 | 接触后最终完成比例、完整保持转化率、保持中断次数、碰撞率、截断成功时间。条件指标需同步报告分母，避免只筛容易接触的回合。 |
| 搜索贡献 | 截断发现时间、发现率、发现前碰撞、发现时执行者位置/速度；固定地图版本。 |
| 价值机制 | ΔQ RMSE、I Q RMSE、带零效应区间的排序准确率、相对于完整后缀的标签误差。尺度归一化用训练尺度并冻结。 |
| 工程成本 | 总仿真步、主步/分支步比、每更新分支数、恢复时间、训练墙钟、推理延迟。 |

### 建议的正式统计协议（后续人工决定执行）

开发与测试场景清单分离，训练种子与评估场景种子分离。资源允许时采用至少 5 个独立训练种子、固定 100 个未参与调参的测试场景；每种子都评估同一批场景。数量可按 pilot 方差调整，禁止看测试结果调超参数。

以训练种子为算法重复单位，报告跨种子均值/区间与每个种子原始结果；对方法差异保留场景配对，可做种子与场景的分层 bootstrap。不能把分支、时间步或同一场景多次重复当独立 N。多组探索比较应披露选择过程。

## 24. 消融：让每个结论都有对应的证据
*实验设计 / 超参数与地图归因*

| 问题 | 消融设计 | 有效结论 |
| --- | --- | --- |
| 是事件监督还是普通平滑？ | 公共方向多尺度 ΔQ vs 相同计算的 Q 平滑/梯度正则；包含同事件样本。 | 不能仅由跨阈值样本上的好结果推广全部状态。 |
| 时域选得好吗？ | P_ind / P_fix / P_min；Hmax∈{5,10,20}，先开发后锁定。 | 用相同已生成轨迹比较标签，再做等预算策略比较。 |
| 尾值可靠吗？ | 完整后缀审计、不同停止时刻、尾值共同偏移诊断、裁剪激活率。 | 共同偏移抵消是条件机制，不能当普适降噪。 |
| 交互有必要吗？ | 四支 TD vs 一阶差分 vs 交互差分；活动对与冻结搜索者负对照。 | 只在真实 I 显著且优于一阶版本时保留。 |
| 差分权重敏感吗？ | λ∈{0.1,0.3,1.0} 仅作起始候选；报告实际损失/梯度比例。 | 不从测试集选最佳权重，不无限扩展网格。 |
| 收益来自地图吗？ | 固定地图主比较；再做 地图旧/新 × 原RL/新RL 的 2×2 配对。 | 分开报告地图主效应、RL 主效应及交互。 |
| 搜索残差参与多少？ | 评估时关闭搜索残差、保留执行残差；再分别关闭执行残差。 | 这是策略权限诊断，不替代重新训练消融。 |

初版建议 λ_I=0，λ_Δ 从 0.1 起做小范围开发；若差分损失尺度很大，先检查标签与采样，而非靠裁剪掩盖。若做尺度归一化/Huber，作为独立设计项记录，所有等数据对照保持一致。

**超参数不是结论**
上述数值是可执行的起始设计，没有项目性能验证。保持原奖励、γ、动作幅度合同与网络维度；不要用改变任务难度或奖励系数掩盖方法的失败。

### 应当停止或降级的情况

① 合法一步残差只造成数值级变化，没有实际事件/回报影响；② 相同分支 TD 已达到同样效果；③ 价值差更准但 Actor 更新或最终策略没有改善；④ 交互低于尾值/恢复误差；⑤ 共同停止时刻的额外成本超过标签收益；⑥ 多步标签与原目标语义冲突尚未解决。

### 未来正确性测试范围

局部新增模块先做任务范围检查；涉及共享核心、运行时或环境合同演化时按仓库要求运行完整相关回归与冻结等价/来源检查。不得通过修改历史哈希、删除来源记录或弱化测试来放行。正式训练不作为代码验证步骤自动启动。

### 建议的论文研究问题

RQ1：在真实残差权限内，现有 Critic 对有限动作造成的控制事件后果是否存在系统误判？
RQ2：相同分支数据与计算预算下，直接差分校准是否改善最终执行策略？
RQ3：共同事件时域是否改善差分标签质量，其净收益来自哪里？
RQ4：发现前的真实二阶动作作用是否足够强，交互校准是否超出一阶监督？

**可使用的暂定贡献表述**
“针对地图先验驱动的多智能体残差控制，研究合法单步干预下的有限动作效应估计，设计原集中 Q 的差分监督，并检验事件停止规则与二阶交互校准的作用。”只有实验完成后，才能补写在哪些指标、哪些预算与哪些场景上优于具体方法。

不建议写：“首次提出差分价值学习”“首次考虑多智能体交互”“证明现有 124D 系统收敛”“显著提升搜索效率”。本轮资料无法支持这些无条件主张。

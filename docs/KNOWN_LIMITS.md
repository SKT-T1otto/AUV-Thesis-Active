# 提炼后仍保留的问题

本次只改变代码组织和入口范围，未改变当前有效算法行为。以下问题从父版本继承：

- gamma=.95使较早动作对100/200步后事件的折扣权重很小；没有发现重复折扣即时reward的错误。
- 提前成功的原始奖励差异可能在终局和保持奖励叠加后被clip=3抹平。
- 持续分散无需新增覆盖也有正奖励，接触重入与保持重置可以再次获得奖励；尚未证明策略实际利用这些激励。
- 在线采样线段检查有几何假阴性，在线分支的clearance语义与D2独立安全层不同。
- 粗体素中free票可能抵消真实命中，最终被判为known_free；D2安全层不能恢复被融合成free的障碍。
- 26射线、局部28D、无剩余时间/前一加速度/完整地图，不构成完整状态或最终物理安全保证。
- 零RL残差仍可能在流场、prior和惯性影响下发生碰撞。
- 旧Linux逐场景数据未提供，不能据汇总结果归因于某个实现问题。

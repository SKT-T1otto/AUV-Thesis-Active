# D2与已接纳执行任务同步

父版本是tracking both，主动恢复继续关闭。新实现仅位于chapter3_bser/r123_task_sync，不改父实现、候选生成、目标函数、控制律、安全阈值、奖励、环境/目标运动、发现/交接/捕获或400步预算。独立task_sync开关关闭时回退父D2数据流。

## 接口行为

执行层继续按原生命周期接纳/释放任务；D2新建议不强制替换活跃根任务。每次评分读取不可变执行回执：实际task_id、已接纳token、根端点、当前物理端点、完整公开route.points/index/revision和状态。

搜索阶段D2重评分使用实际执行回执；重分配时活跃承诺作为固定项，其他搜索器可获得新建议。对释放、不可达、等待任务只计当前位置的静态探测，不给旧根任务未来路线虚构收益；CONNECTOR按实际公开connector路线计，不能被安装成新根任务。FROZEN与交接后绕过搜索同步，保留父捕获流程。初始尚无回执时使用父D2初始分配。

D2 proposal仍单独保留。评分用的物理回执ID/connector端点不会被写回为新搜索根任务。新任务建议只在原生命周期明确接纳后进入后续current-plan评分；建议最终评分中的新任务属于待接纳的前瞻项，下一次current rescore必须再读取实际回执。记录scoring.scope区分这两种计算。

保留完整已接纳路线，不按index裁掉已走前缀；没有混入独立的“剩余路径检测模型”改动。重复访问、候选并列偏置、低cap之后的路点减速都未在此版本调整。不同路线带来的任务结果和计算成本仍需实际对照评估。

回执读取不会调用observe、路径查询、环境step或随机数；不修改任务/route进度，不使用真值。sync_scoring记录每次实际固定/当前评分输入与回执的一致性并遇错停止；task_sync.receipts保存完整公开路线。附带同步评分耗时、调用次数与执行层route查询数，供成本诊断。旧基线没有同口径route查询计数，保持未知；不同运行的wall_seconds不作为受控加速结论。

## Windows与Linux验证

合成检查覆盖不强制接纳、任务身份、完成后的等待及新token接纳、未分配/冻结、CONNECTOR/不可达、回执副本、真实D2评分/冻结和开关关闭行为。真实短检查严格4次初始化×最多32步：父tracking、sync关闭、sync开启（0000），以及sync开启（0002）；前两条完整trace必须逐字段相等。没有训练或权重恢复。

这不能证明400步内不会长期等待或完整任务收益提高；长时域结果必须由三场有限对照检查。新身份由独立manifest记录，旧tracking身份和历史结果仍原样保留。Windows验证不能代替当前源码的Linux短验证准入。

## Linux命令

原用户分工仍为Windows改码与有界验证，用户手动运行Linux。先准备：读取已完成both的0000—0002原始数据作为A组，不重跑A；运行4×32步短检查，最多128新物理步；没有完整评估或训练。

```bash
conda activate AUV
cd ~/AUV-Thesis/AUV-Thesis-R123
(
  set -euo pipefail
  git pull --ff-only
  OLD=work/collision_terminal/r123_tracking_20261117_121047_2475513
  BASE="work/collision_terminal/r123_task_sync_$(date +%Y%m%d_%H%M%S)_$$"
  test -n "$OLD" && test -f "$OLD/both/completed.json"
  bash scripts/r123_task_sync_prepare_linux.sh "$OLD" "$BASE"
)
```

准备结束会打印BASE。**新终端或上述子shell结束后，先将真实BASE路径重新赋值**，随后执行新B组。B只运行0000—0002，各最多400步，最多1200新增物理步；规则控制、不训练、不加载模型，不自动运行其余三场或任何矩阵。

```bash
BASE='work/collision_terminal/r123_task_sync_这里换成准备阶段打印的真实编号'
test -n "$BASE" && test -f "$BASE/session.env"
bash scripts/r123_task_sync_evaluate_linux.sh "$BASE"
```

不要直接执行含占位文字的BASE。每25步显示进度；日志prepare.log、validation.log、evaluate.log、report.log在BASE内。需sync/completed.json及report/report.json同时存在；最终打印ALL THREE SCENES COMPLETED才算完成。set -euo pipefail让命令/管道遇错停止；输出目录拒绝覆盖，不读取不存在的latest文件，也不使用sudo修路径。

Linux本轮总预算最多128准备步+1200评估步=1328步。若修复没有任务收益或有副作用，按paired_delta、任务完成/等待、碰撞及成本报告事实；不能仅靠receipt_violations=0宣称算法有效。旧成功场的必要回归另行决定，不自动追加。

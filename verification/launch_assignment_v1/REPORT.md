# 同时出航分工研究 · 第 1 步

本次准备冻结用于确定本艇分工的实验协议、场景家族和盲测边界。比较目标为给定决策前信息、合法候选和同一续程规则时的原生终局成功概率。每艇部署时只读自身历史、局部候选和已送达的消息。

## 复现清单

在仓库根目录使用项目的 Python 环境执行下列命令。原生 M20 生成器会生成几何场景并检查其数据集可行性，任务回合、任务物理步、训练更新与权重加载预算均为零。

```shell
python -B -m tools.launch_assignment_study prepare --output verification/launch_assignment_v1
python -B -m unittest checks.test_launch_assignment_prepare
```

指定一个新输出目录可生成独立副本。向同一目录重复准备，会比较已有清单的完整字节。已有不同内容时命令退出，并保留原文件。来源锁记录了 Git 基线、生成器与输入文件的 SHA-256、参考软件版本及新场景身份摘要。[研究配置](../../configs/launch_assignment_v1/study.json) · [来源锁](../../provenance/launch_assignment_v1.json)

## 家族和盲测

9 项历史输入登记了 140 条来源记录，覆盖 134 个不同的物理家族。24 个历史扩场案例全部归入开发集，包括 0003、0010、0012、0019，以及已检查过同一步命中或末段切换的案例。原 R123 筛查的 62 个物理指纹全部命中登记册。历史测试材料在本研究中只作身份保留，原研究的标签访问约定继续有效。[历史身份登记册](../../configs/launch_assignment_v1/history.json)

原生生成器使用种子 2026112401 一次产生 56 个新场景，按预定配额增加 8 个开发、24 个校准和 24 个盲测家族。先按任一共同物理键把记录连接，再在家族级别分组。物理键包括原有物理指纹、出航艇位、按几何排序的布局、原生轨迹摘要、运动起点和场景种子。原生轨迹摘要本身含布局，运动起点额外阻止相同轨迹因布局标识变化而跨组。这种保守处理可能把部分不同任务归为同一家族。相同编号在不同生成批次可重用，场景名称不参与分组。每个后续路线、末段及续程种子分支都继承出航家族。

“交接价值优先 × 直连末段”在开发和校准家族均封存，其他三个配置只能在各自规定的开发或校准用途内使用。盲测家族四个配置均封存。准备清单公开划分和复现所需的身份信息，未采集任何正式分支的轨迹、首次收包状态或终局标签。家族标识和随机种子仅供离线实验使用。

版本 1 采用 0.05 的绝对成功概率损失主容差，另列 0.025 和 0.10，并采用 0.05 的同时误差水平。候选提案器通过历史文件哈希和参数哈希固定。后续搜索规则在此阶段冻结其定义，正式取数前还需固定各自的实现和权重。每艇至多两项有效候选，单家族一次出航在一个配置内的先导裁判预算最多为八种联合指派、每种四个配对续程、每条 400 步。是否达到所需统计精度由未来的独立终局决定。

## 历史版本复核

持有原归档的工作区可以额外传入 `--verify-history`。该选项逐一复核原归档字节、场景身份投影、历史来源清单、回归测试源和提案器文件摘要。普通准备只依赖本版本随仓库发布的文件。

```shell
python -B -m tools.launch_assignment_study prepare --output verification/launch_assignment_v1 --verify-history
python -B -m unittest checks.test_handoff_records checks.test_handoff_pairs checks.test_handoff_bounds checks.test_local_ctde checks.test_neighbor_ctde checks.test_r123_task_sync checks.test_r123_final_leg
```

原扩场和末段清单分别与提交 `98630ea` 和 `7810c66` 的文件字节一致。交接只读版的 10 项源码与输入、配对版的 5 项源码、本艇与邻艇清单的 165 和 7 项源码均按各自来源口径复核。旧配对原档的短前缀与完整终局各核验了四对。上述历史运行时与结果属于其原版本。

## 验收记录

工作区使用完整历史复核模式执行一次准备。从候选 Git 树提取可发布的代码和输入，在独立目录、独立 Python 进程中重新生成全部新场景并执行普通准备。两份清单长度均为 160,364 字节，SHA-256 均为 `a06e8e8a4db3b1a99db512e1a710915cf7f597a544e5bb4e2a1ca74d37e7fccc`。

最终登记 190 个家族、196 条来源记录，分别为 142 个开发家族、24 个校准家族和 24 个盲测家族。对每一对分组独立比较六类物理身份键，每项交集大小均为零。独立副本的 8 项准备测试全部通过，包括跨键传递关联、历史归组、配额冲突、随机流隔离、盲测配置与并发发布。受保护的 CH3、CH4、CH5 按原基线逐文件复核，分别有 369、103、318 个文件匹配。

最终工作区合并执行 8 项新增测试和 65 项既有测试，73 项全部通过。既有测试覆盖交接记录、同状态配对、区间、本艇与邻艇信息隔离、执行回执及末段控制。此次验收未运行会训练模型的邻艇检查入口。
